# Store API 🛒

A *Node.js RESTful API* for managing store operations.  
This project demonstrates building a backend with *Express.js, **MongoDB (Atlas), **Redis caching, **TLS for secure communication, and **Nodemailer for sending emails*.

---

## 🚀 Features
- User authentication & authorization (JWT-based)
- Product CRUD (Create, Read, Update, Delete)
- MongoDB Atlas for database
- Redis for caching frequently accessed data
- TLS/SSL configuration for secure API requests
- Nodemailer integration for email notifications
- Environment variable management with .env
- Proper error handling & logging

---

## 🛠️ Tech Stack
- *Backend:* Node.js, Express.js
- *Database:* MongoDB Atlas
- *Cache:* Redis
- *Security:* TLS/SSL
- *Email:* Nodemailer
- *Others:* dotenv, morgan, bcrypt, jsonwebtoken
